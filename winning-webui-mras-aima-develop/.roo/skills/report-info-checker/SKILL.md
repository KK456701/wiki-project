# 报告信息检查 Skill

## When to use

- 用户请求生成报告，但提供的信息不完整
- 需要确认报告生成所需的数据来源、统计周期、目标值等
- 需要适配不同模型能力的信息密度

## When NOT to use

- 用户已提供完整信息，可直接生成报告
- 仅需简单问答，不涉及报告生成

## 工作流程

### 1. 识别报告类型

根据用户请求，识别报告类型并定位对应的模型文件：

| 报告类型 | 事件编码 | 模型文件路径 |
|---------|---------|-------------|
| 首诊责任制报告 | CORE_FDR | `model/CORE_FDR_源表模型.md` |
| 查房制度报告 | CORE_WARDROUND | `model/CORE_WARDROUND_源表模型.md` |
| 会诊制度报告 | CORE_CONSUL | `model/CORE_CONSUL_源表模型.md` |
| ... | ... | ... |

**操作**：读取对应的模型文件，提取：
- 对应指标名称
- 目标表名
- 关键字段
- 应用 SQL（`synthesis/application/` 下）

### 2. 确认目标模型

报告将由用户指定的目标模型生成（而非当前模型）。需要询问用户选择或输入目标模型：

**步骤 2.1 — 询问用户**

使用 `ask_followup_question` 工具，提供以下选项：

| 选项 | 模型示例 | 说明 |
|------|---------|------|
| 大参数商业模型 | deepseek-v4, glm-5.2, qwen-max | 高能力，信息密度低 |
| 中等参数模型 | qwen-plus, gpt-4o-mini | 中能力，信息密度中 |
| 本地小模型 | qwen3:8b, gemma4:12b | 低能力，信息密度高 |
| 自行输入 | 用户输入具体模型名称 | 根据模型名称判断能力等级 |

**步骤 2.2 — 判定能力等级**

根据用户选择或输入的模型名称，参照 [references/model-profiles.md](references/model-profiles.md) 判定能力等级：

| 模型等级 | 典型模型 | 参数量参考 | 信息密度要求 |
|---------|---------|-----------|-------------|
| 高能力 | deepseek-v4, glm-5.2, qwen-max | ≥70B 或商业旗舰 | 可处理模糊描述，允许部分推断 |
| 中能力 | qwen-plus, gpt-4o-mini, qwen3:32b | 7B-70B 或商业标准 | 需要明确的数据来源和统计口径 |
| 低能力 | qwen3:8b, gemma4:12b, llama3:8b | <7B 本地部署 | 需要完整、精确的结构化数据 |

**判定规则**（当用户自行输入模型名称时）：
1. 模型名含 `:8b` / `:7b` / `:4b` / `:3b` / `:1b` 等小参数量标签 → 低能力
2. 模型名含 `:32b` / `:26b` / `:14b` 等中等参数量标签 → 中能力
3. 模型名含 `:72b` / `:110b` 或为商业旗舰（deepseek-v4, glm-5.2, qwen-max）→ 高能力
4. 无法判断时，默认按中能力处理，并告知用户

### 3. 执行信息检查

根据模型能力等级，输出对应的检查清单。

#### 通用检查项（所有模型必需）

- [ ] **统计周期**：开始日期、结束日期
- [ ] **输出路径**：报告输出目录和文件名格式
- [ ] **报告类型**：确认事件编码和指标

#### 高能力模型检查项（可推断）

- [ ] 数据来源（可从数据库连接推断）
- [ ] 目标值（可从目标表查询）
- [ ] 科室范围（可默认全部科室）

#### 中能力模型检查项（需明确）

- [ ] 数据来源：数据库连接 or 文件导入
- [ ] 目标值：具体数值或目标编码
- [ ] 报告层级：概览 / 科室 / 明细

#### 低能力模型检查项（需完整提供）

- [ ] 完整的数据库连接字符串
- [ ] 精确的目标值（百分比）
- [ ] 科室列表（如需筛选）
- [ ] 分子/分母的具体计算口径
- [ ] 报告模板结构

### 4. 输出检查结果

根据模型能力，输出适配的检查报告：

```markdown
# 报告信息检查报告

## 基本信息
- 报告类型：{报告类型}
- 事件编码：{事件编码}
- 统计周期：{开始日期} 至 {结束日期}

## 模型适配
- 目标模型：{用户选择的模型名称}
- 能力等级：{高/中/低}
- 信息密度：{低/中/高}

## 已提供信息
| 项目 | 值 | 状态 |
|------|-----|------|
| 统计周期 | 2025-01-01 至 2025-03-01 | ✅ |
| ... | ... | ... |

## 缺失信息（按优先级）

### 必须提供
- [ ] {缺失项1}
- [ ] {缺失项2}

### 建议提供
- [ ] {缺失项3}

## 下一步操作
1. {操作指引1}
2. {操作指引2}
```

## 示例

### 输入（首诊责任制报告）

```
生成首诊责任制报告，统计周期 2025-01-01 到 2025-03-01
```

### 输出（低能力模型适配）

```markdown
# 报告信息检查报告

## 基本信息
- 报告类型：首诊责任制报告
- 事件编码：CORE_FDR
- 对应指标：患者入院48小时内转科的比例
- 统计周期：2025-01-01 至 2025-03-01

## 模型适配
- 目标模型：qwen3:8b（用户指定）
- 能力等级：低
- 信息密度：高（需要完整数据）

## 已提供信息
| 项目 | 值 | 状态 |
|------|-----|------|
| 统计周期 | 2025-01-01 至 2025-03-01 | ✅ |
| 输出目录 | report/ | ✅ |
| 文件名格式 | {yyyy_MM_dd-HH_mm_ss}.md | ✅ |

## 缺失信息（必须提供）

### 数据来源
- [ ] 数据库连接字符串（如：`Server=xxx;Database=xxx;...`）
- [ ] 或已导出的数据文件路径

### 目标值
- [ ] 目标值编码：`HXZD-001-001` 对应的具体数值（如：`2.5%`）

### 统计口径
- [ ] 分子定义：入院48小时内转科患者人次数
- [ ] 分母定义：同期入院患者总人次数

### 报告内容
- [ ] 是否需要概览层（汇总值 + 目标对比）
- [ ] 是否需要科室层（按科室拆分）
- [ ] 是否需要明细层（逐患者记录）

## 下一步操作
1. 提供数据库连接信息，或上传数据文件
2. 确认目标值（可从 MRAS_TARGET_DEFINITION 表查询）
3. 确认报告内容层级
```
