# 临床用血后评估记录率

## 检索卡片

- 指标编码：HXZD-016-001
- 所属制度：[[HXZD-016-临床用血审核制度]]
- 默认口径：[[HXZD-016-001-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

输血治疗后规范书写评估输血记录例次数占同期临床输血治疗病例总例次数的比例。

## 计算公式

分子：输血治疗后规范书写评估输血记录例次数
分母：同期临床输血治疗病例总例次数
公式：输血治疗后规范书写评估输血记录例次数 / 同期临床输血治疗病例总例次数 * 100%
