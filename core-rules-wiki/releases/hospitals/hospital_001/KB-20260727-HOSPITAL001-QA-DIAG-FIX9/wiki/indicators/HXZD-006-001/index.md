# 非计划再次住院/手术患者疑难病例讨论完成率

## 指标定义

对非计划再次住院/手术患者进行疑难病例讨论的数量占同期非计划再次住院/手术的数量的比例。

## 计算公式

分子：对非计划再次住院/手术患者进行疑难病例讨论的数量
分母：同期非计划再次住院/手术的数量
公式：对非计划再次住院/手术患者进行疑难病例讨论的数量 / 同期非计划再次住院/手术的数量 * 100%
