# 术中自体血回输率

## 指标定义

术中使用自体血回输的患者数量占同期术中进行输血患者总数量的比例。

## 计算公式

分子：术中使用自体血回输的患者数量
分母：同期术中进行输血患者总数量
公式：术中使用自体血回输的患者数量 / 同期术中进行输血患者总数量 * 100%
