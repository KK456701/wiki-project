# 四级手术术前多学科讨论完成率

- 所属制度：[[HXZD-012-手术分级管理制度]]

## 指标定义

术前完成多学科讨论的四级手术例数占同期四级手术总例数的比例。

## 计算公式

分子：术前完成多学科讨论的四级手术例数
分母：同期四级手术总例数
公式：术前完成多学科讨论的四级手术例数 / 同期四级手术总例数 * 100%

## 指标说明

限制类技术按照四级手术进行管理。

## 指标意义

反映四级手术术前多学科讨论制度执行情况。
