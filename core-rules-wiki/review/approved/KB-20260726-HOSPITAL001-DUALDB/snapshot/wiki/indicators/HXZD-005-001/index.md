# 四级手术患者手术当日床旁交接班占比

## 检索卡片

- 指标编码：HXZD-005-001
- 所属制度：[[HXZD-005-值班和交接班制度]]
- 默认口径：[[HXZD-005-001-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

四级手术患者手术当日进行床旁交接班的患者数量占同期进行四级手术的患者总数量的比例。

## 计算公式

分子：四级手术患者手术当日进行床旁交接班的患者数量
分母：同期进行四级手术的患者总数量
公式：四级手术患者手术当日进行床旁交接班的患者数量 / 同期进行四级手术的患者总数量 * 100%

## 指标说明

1.本指标中四级手术是指按各医疗机构制定的本机构手术分级管理目录中按四级手术管理的手术/操作。
2.手术当日进行床旁交接班应当具备相关纸质或影像记录。

## 指标意义

反映交接班制度落实和管理情况。
