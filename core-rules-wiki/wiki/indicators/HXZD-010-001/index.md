# 长期医嘱当日终止率

## 检索卡片

- 所属制度：[[HXZD-010-查对制度]]

## 指标定义

开具长期医嘱后当日终止执行的医嘱数量占同期开具长期医嘱总数量的比例。

## 计算公式

分子：开具长期医嘱后当日终止执行的医嘱数量
分母：同期开具长期医嘱总数量
公式：开具长期医嘱后当日终止执行的医嘱数量 / 同期开具长期医嘱总数量 * 100%
