- 当前执行轮自动展开，历史轮次保留折叠状态。

- “重新抽取并核对”“修改抽取 SQL”“修改统计 SQL”三个动作独立展示。

- 自主模式下上述标准表单完全不渲染。

- 正式/影子分子分母均为10/417，结果均为0.023980815347。
- 页面明确说明 SQL 未变化，没有生成候选 SQL或医院草稿。[截图](16-refresh-shadow-result.png)
- 实施明确确认后复用正式链路重算，状态为 `DATA_REFRESHED`；前后均为10/417。[截图](17-formal-recalculated.png)

本地当前批次没有“业务源已有、正式表暂缺”的天然差异，因此浏览器实际得到的是“无变化”结论；有差异时所用的记录集差异、影子表、正式确认动作和状态流转与下一节候选 SQL 试跑共用同一套实现，自动测试覆盖差异分支。
