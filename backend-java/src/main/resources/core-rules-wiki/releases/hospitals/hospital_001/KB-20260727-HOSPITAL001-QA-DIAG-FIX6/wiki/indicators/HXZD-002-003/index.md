# 住院患者非计划手术率

## 检索卡片

- 指标编码：HXZD-002-003
- 所属制度：[[HXZD-002-三级查房制度]]
- 默认口径：[[HXZD-002-003-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

行非计划手术的住院患者人次数占同期住院患者总人次数的比例。

## 计算公式

分子：行非计划手术的住院患者人次数
分母：同期住院患者总人次数
公式：行非计划手术的住院患者人次数 / 同期住院患者总人次数 * 100%
