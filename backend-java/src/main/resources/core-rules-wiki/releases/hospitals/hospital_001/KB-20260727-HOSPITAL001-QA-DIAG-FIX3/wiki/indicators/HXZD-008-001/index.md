# 术前讨论完成率

## 检索卡片

- 指标编码：HXZD-008-001
- 所属制度：[[HXZD-008-术前讨论制度]]
- 默认口径：[[HXZD-008-001-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

完成术前讨论的手术例数占同期手术总例数的比例。

## 计算公式

分子：完成术前讨论的手术例数
分母：同期手术总例数
公式：完成术前讨论的手术例数 / 同期手术总例数 * 100%

## 指标说明

除以抢救生命为目的的急诊手术外，术前讨论完成时间晚于手术医嘱开具时间和手术同意书签署时间的病例视为未完成术前讨论。

## 指标意义

反映术前讨论完成情况。
