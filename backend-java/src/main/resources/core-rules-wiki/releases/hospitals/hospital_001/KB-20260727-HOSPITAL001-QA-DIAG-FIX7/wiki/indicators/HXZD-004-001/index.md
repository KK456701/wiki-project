# 手术患者特级护理/一级护理出院率

## 检索卡片

- 指标编码：HXZD-004-001
- 所属制度：[[HXZD-004-分级护理制度]]
- 默认口径：[[HXZD-004-001-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

手术患者出院时为特级护理/一级护理级别的患者数量占同期手术患者总数量的比例。

## 计算公式

分子：手术患者出院时为特级护理/一级护理级别的患者数量
分母：同期手术患者总数量
公式：手术患者出院时为特级护理/一级护理级别的患者数量 / 同期手术患者总数量 * 100%

反映对住院患者进行分级护理动态调整的情况。
