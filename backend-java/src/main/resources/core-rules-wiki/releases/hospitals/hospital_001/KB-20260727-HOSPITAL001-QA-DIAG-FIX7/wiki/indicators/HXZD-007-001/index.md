# 急危重症患者抢救成功率

## 检索卡片

- 指标编码：HXZD-007-001
- 所属制度：[[HXZD-007-急危重患者抢救制度]]
- 默认口径：[[HXZD-007-001-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

急危重症患者抢救成功的例次数占同期急危重症患者抢救的总例次数的比例。

## 计算公式

分子：急危重症患者抢救成功的例次数
分母：同期急危重症患者抢救的总例次数
公式：急危重症患者抢救成功的例次数 / 同期急危重症患者抢救的总例次数 * 100%

## 指标说明

本指标中抢救成功指急危重患者经抢救后存活超过24小时或存活至下一次抢救开始。

## 指标意义

反映急危重症患者救治质量。
