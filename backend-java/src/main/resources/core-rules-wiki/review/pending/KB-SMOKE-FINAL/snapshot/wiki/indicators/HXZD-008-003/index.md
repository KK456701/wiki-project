# 术前讨论计划手术一致率

## 检索卡片

- 指标编码：HXZD-008-003
- 所属制度：[[HXZD-008-术前讨论制度]]
- 默认口径：[[HXZD-008-003-company-default]]
- SQL规格：[[sql-spec]]

## 指标定义

实际开展手术与术前讨论计划手术一致的手术例数占同期手术总例数的比例。

## 计算公式

分子：实际开展手术与术前讨论计划手术一致的手术例数
分母：同期手术总例数
公式：实际开展手术与术前讨论计划手术一致的手术例数 / 同期手术总例数 * 100%
