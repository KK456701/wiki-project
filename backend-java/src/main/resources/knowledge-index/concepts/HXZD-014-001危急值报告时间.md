# HXZD-014-001 — 危急值报告时间

> **制度：** 危急值报告制度 | **事件编码：** CORE_CV_RPT
> **导向：** 逐步降低 | **分类：** 时限类

## 指标定义

将出现危急值到临床科室获取危急值的时间，由长到短排序后取其中位数。

## 计算公式

危急值报告时间(中位数) = X(n+1)/2, n为奇数；
危急值报告时间(中位数) = (Xn/2 + Xn/2+1)/2, n为偶数

## 说明

1. n为实际报告的危急值项目数; X为出现危急值到临床科室获取危急值的时间。
2.分别计算住院、门诊、急诊危急值报告时间。

## 指标意义

反映危急值上报的效率。
