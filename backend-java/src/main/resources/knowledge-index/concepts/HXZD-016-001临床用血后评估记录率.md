# HXZD-016-001 — 临床用血后评估记录率

> **制度：** 临床用血审核制度 | **事件编码：** CORE_BLOOD_RECORD
> **导向：** 逐步提高 | **分类：** 内容完整性

## 指标定义

输血治疗后规范书写评估输血记录例次数占同期临床输血治疗病例总例次数的比例。

## 计算公式

分子：输血治疗后规范书写评估输血记录例次数
分母：同期临床输血治疗病例总例次数
公式：输血治疗后规范书写评估输血记录例次数 / 同期临床输血治疗病例总例次数 * 100%
