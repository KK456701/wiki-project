# HXZD-004-001 — 手术患者特级护理/一级护理出院率

> **制度：** 分级护理制度 | **事件编码：** GRADE_CARE
> **导向：** 逐步降低 | **分类：** 逻辑判定类

## 指标定义

手术患者出院时为特级护理/一级护理级别的患者数量占同期手术患者总数量的比例。

## 计算公式

分子：手术患者出院时为特级护理/一级护理级别的患者数量
分母：同期手术患者总数量
公式：手术患者出院时为特级护理/一级护理级别的患者数量 / 同期手术患者总数量 * 100%

——

## 指标意义

反映对住院患者进行分级护理动态调整的情况。

## 统计口径

**分子：** 手术患者出院时为特级护理/一级护理级别的患者数量
> 1、单位时间内出区的手术患者中，最后一条护理医嘱为特级或一级护理的患者数
2、说明：手术患者判断时，只需要统计手术类型为手术、介入治疗，排除诊断性操作、治疗性操作的数据以及日间手术。
