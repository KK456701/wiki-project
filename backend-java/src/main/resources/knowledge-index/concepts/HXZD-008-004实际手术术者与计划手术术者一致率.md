# HXZD-008-004 — 实际手术术者与计划手术术者一致率

> **制度：**  | **事件编码：** CORE_OP_DISC
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

实际开展手术术者与计划手术术者一致的手术例数占同期手术总例数的比例。

## 计算公式

分子：实际开展手术术者与计划手术术者一致的手术例数
分母：同期手术总例数
公式：实际开展手术术者与计划手术术者一致的手术例数 / 同期手术总例数 * 100%

## 说明

——

## 指标意义

反映手术管理的规范性。

## 统计口径

**分子：** 实际开展手术术者与计划手术术者一致的手术例数
> 1、单位时间内完成手术的患者中，手术记录（病历）中手术主刀医师与手术申请单（医嘱）中一致的数量
2、说明：手术患者判断时，只需要统计手术类型=手术、介入治疗，排除诊断性操作、治疗性操作的数据
3、手术记录和手术医嘱有关联关系
