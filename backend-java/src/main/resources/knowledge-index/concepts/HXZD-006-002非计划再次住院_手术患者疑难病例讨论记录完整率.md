# HXZD-006-002 — 非计划再次住院/手术患者疑难病例讨论记录完整率

> **制度：**  | **事件编码：** CORE_DIFFI_EMR
> **导向：** 逐步提高 | **分类：** 内容完整性

## 指标定义

对非计划再次住院/手术患者进行疑难病例讨论并将讨论结论记入病历的数量占同期对非计划再次住院/手术患者进行疑难病例讨论的数量的比例。

## 计算公式

分子：对非计划再次住院/手术患者进行疑难病例讨论并将讨论结论记入病历的数量
分母：同期对非计划再次住院/手术患者进行疑难病例讨论的数量
公式：对非计划再次住院/手术患者进行疑难病例讨论并将讨论结论记入病历的数量 / 同期对非计划再次住院/手术患者进行疑难病例讨论的数量 * 100%

## 指标意义

反映疑难病例讨论制度落实和管理情况。

## 统计口径

**分子：** 对非计划再次住院/手术患者进行疑难病例讨论并将讨论结论记入病历的数量
> 1、单位时间内出区的非计划再入院/手术患者患者中，疑难病例讨论记录（病历）已提交状态病历的数量
2、非计划再次入院定义：患者31天内再次住院，并且上次住院的病案首页“31天内再住院计划=无”，且患者本次入院主诊断和上次出院主诊断的诊断编码前5个字符相同（（例如诊断编码为Z51.003，则前5个字符为Z51.0））。
4、非计划再次手术定义：取手术医嘱“非计划二次手术”标记
5、说明：手术患者判断时，只需要统计手术类型为手术、介入治疗，排除诊断性操作、治疗性操作的数据
