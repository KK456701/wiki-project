# 查询结果/说明文档模板

> 用于 `queries/` 目录下的查询结果存档或完整说明文档。
> 变量用 `{var}` 表示，生成时替换为实际值。

## 文件命名

```
{描述性文件名}.md
```

例：`35指标45衍生指标完整说明文档.md`、`20260728_首诊转科率查询结果.md`

---

## 使用指南

### 适用场景

| 场景 | 示例 |
|------|------|
| 数据集完整说明 | 35指标×45衍生指标完整说明文档 |
| SQL 查询结果存档 | 20260728_首诊转科率月度查询结果 |
| 多维度统计汇总 | 16制度数据覆盖度统计 |
| 数据质量检查报告 | 目标表枚举值异常检查结果 |

### 命名建议

- 完整说明文档：`{范围}完整说明文档.md`
- 查询结果存档：`{YYYYMMDD}_{查询主题}.md`
- 统计汇总：`{维度}统计汇总.md`

### 内容要求

- **概述表格**放在文档开头，让读者快速了解文档范围和关键数字
- 每个章节用二级标题 `##` 分隔
- 表格用于结构化数据展示
- 所有链接使用 `[[wikilink]]` 交叉引用已有页面
- 文件末尾用 HTML 注释记录元信息
- 页面类型设为 `type: query`

### tags 建议

| 标签 | 适用场景 |
|------|---------|
| `完整文档` | 覆盖全量指标的说明文档 |
| `查询结果` | 单次 SQL 查询结果存档 |
| `数据统计` | 数据量、覆盖率等统计汇总 |
| `指标说明` | 指标维度的说明文档 |
| `制度维度` | 按制度维度的汇总说明 |
