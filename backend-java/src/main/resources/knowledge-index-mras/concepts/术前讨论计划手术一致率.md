# HXZD-008-003 — 术前讨论计划手术一致率

> **制度：**  | **事件编码：** CORE_OP_DISC
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

实际开展手术与术前讨论计划手术一致的手术例数占同期手术总例数的比例。

## 计算公式

分子：实际开展手术与术前讨论计划手术一致的手术例数
分母：同期手术总例数
公式：实际开展手术与术前讨论计划手术一致的手术例数 / 同期手术总例数 * 100%

## 说明

——

## 指标意义

反映术前讨论质量。

## 统计口径

**分子：** 实际开展手术与术前讨论计划手术一致的手术例数
> 1、单位时间内完成手术的患者中，手术记录（病历）的手术名称与术前讨论记录（病历）中的手术名称一致的数量（一条记录中有多个手术，任意一个相同，即算作一致）
2、说明：手术患者判断时，只需要统计手术类型=手术、介入治疗，排除诊断性操作、治疗性操作的数据
3、说明：EMR的术前讨论记录跟手术记录目前没有关联关系，可通过手术记录创建前48h内，最近的一份术前讨论记录来做对比。
4、一个人多次手术算多次。
