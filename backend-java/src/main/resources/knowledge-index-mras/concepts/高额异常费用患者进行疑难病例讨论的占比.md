# HXZD-006-003 — 高额异常费用患者进行疑难病例讨论的占比

> **制度：**  | **事件编码：** CORE_DIFFI_EMR_SECOND
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

对产生高额异常费用患者进行疑难病例讨论的数量占同期高额异常费用患者数量的比例。

## 计算公式

分子：对产生高额异常费用患者进行疑难病例讨论的数量
分母：同期高额异常费用患者数量
公式：对产生高额异常费用患者进行疑难病例讨论的数量 / 同期高额异常费用患者数量 * 100%

## 说明

高额异常费用患者是指一个住院周期内产生的医疗费用在20万元以上的患者（各地可根据本辖区实际情况划定高额异常费用患者的费用额度）。

## 指标意义

反映疑难病例讨论制度落实和管理情况。

## 统计口径

**分子：** 对产生高额异常费用患者进行疑难病例讨论的数量
> 1、单位时间出区患者中，属于高额费用患者，且完成了疑难病历讨论记录的患者数
2、由于各地区对高额异常费用定义会有不同，这个数值可配置
3、一个患者单次住院最多统计为1
