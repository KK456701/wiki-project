# HXZD-009-002 — 医务部门组织讨论的死亡病例与发生纠纷的死亡病例比值

> **制度：**  | **事件编码：** CORE_DEATH
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

医务部门组织进行死亡病例讨论的病例数量与同期发生医疗纠纷的死亡病例数量的比值。

## 计算公式

分子：医务部门组织进行死亡病例讨论的病例数量
分母：同期发生医疗纠纷的死亡病例数量
公式：医务部门组织进行死亡病例讨论的病例数量 ： 同期发生医疗纠纷的死亡病例数量
