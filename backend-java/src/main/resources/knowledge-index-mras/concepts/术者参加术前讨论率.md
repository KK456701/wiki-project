# HXZD-008-002 — 术者参加术前讨论率

> **制度：**  | **事件编码：** CORE_OP_DISC
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

术者参加术前讨论的手术例数占同期进行术前讨论手术总例数的比例。

## 计算公式

分子：术者参加术前讨论的手术例数
分母：同期进行术前讨论手术总例数
公式：术者参加术前讨论的手术例数 / 同期进行术前讨论手术总例数 * 100%

## 说明

本指标中术者是指手术的主要完成人。

## 指标意义

反映术前讨论规范性。

## 统计口径

**分子：** 术者参加术前讨论的手术例数
> 单位时间内完成的术前讨论记录（病历）中，讨论人或主持人包含手术记录（病历）中手术医师的数量
说明：EMR的术前讨论记录跟手术记录没有关联关系，本指标通过手术记录创建前48h内书写的最近一份术前讨论记录来做对比
