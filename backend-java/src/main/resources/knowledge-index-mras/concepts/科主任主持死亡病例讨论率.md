# HXZD-009-003 — 科主任主持死亡病例讨论率

> **制度：**  | **事件编码：** CORE_DEATH
> **导向：** 逐步提高 | **分类：** 逻辑判定类

## 指标定义

死亡病例讨论由科主任主持的病例数量占同期死亡病例总数量的比例。

## 计算公式

分子：死亡病例讨论由科主任主持的病例数量
分母：同期死亡病例总数量
公式：死亡病例讨论由科主任主持的病例数量 / 同期死亡病例总数量 * 100%
